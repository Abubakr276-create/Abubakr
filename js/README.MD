В данной папке размещаем скриптовые файлы *.js

Динамическая составляющая макета:

1. У элемента big-slider будет анимирован текст для h1 class="curved".

2. При нажатии на кнопку поиск, будет появляться js pop up окно.

3. Cоздаем слушатель события scroll. Когда пользователь прокручивает страницу, элемент с классом curved, находящийся внутри big-slider, будет анимирован плавно исчезать. В консоли выводим сообшение, событие произошло, и выводим текущую позицию прокрутки.

4. Доделана анимация, теперь при прокрутке вверх текст сново появляеться.

5. Добавлена кнопка Go to top.

6. Добавлена функция которая выводит элементы h3 при прокрутке страницы.
